# SparkDay 閃光待辦

SparkDay（閃光待辦）是一款輕量的待辦事項管理網頁，適合用來整理工作、個人生活、學習與健康目標。你可以為任務設定優先順序和截止日期，追蹤完成進度，並依照自己的習慣調整介面。

## 開始使用

建議使用Chrome以獲得最佳體驗。
開啟 [SparkDay 閃光待辦](https://eevrt0404.github.io/sparklish/) 即可開始體驗

## 任務管理

1. 在頁面下方輸入任務名稱，按 Enter 或「新增」建立任務。
2. 建立前可選擇低、中、高優先順序、工作／個人／學習／健康分類，以及選填截止日期。
3. 點選任務左側的核取按鈕標記完成；點選鉛筆可修改名稱，垃圾桶可刪除任務。
4. 使用左側的「全部」、「進行中」或「已完成」查看不同狀態，也能依分類篩選。
5. 使用上方搜尋欄尋找任務，或切換排序方式：建立時間、優先順序、截止日期。
6. 左側會顯示任務數量與整體完成率。「清理已完成」會移除所有已完成任務。

## 個人化與資料備份

點選側欄的齒輪按鈕開啟系統偏好設定。可選擇佈景主題、設定顯示名稱、新任務的預設優先順序與分類，並開關完成彩帶和背景粒子效果。完成後按「儲存變更」；佈景主題會立即套用。

任務與偏好設定預設儲存在目前瀏覽器的本機儲存空間，不會自動出現在其他裝置。定期使用匯出按鈕下載 JSON 備份；匯入 JSON 會以檔案中的任務清單**取代目前清單**，匯入前請先匯出備份。不要匯入來源不明或未確認格式的檔案。

## 登入系統

登入 Google 後，任務會同步至該帳號的 Firestore。第一次登入時若偵測到本機任務，請留意選擇：以本機資料覆蓋雲端，或保留本機資料並載入雲端清單。覆蓋會取代該帳號原有雲端任務，請先確認或匯出備份。登出不等於刪除帳號雲端資料；「重置並清除所有數據」則會清除本機資料與登入帳號的雲端任務，且**無法復原**！

## 使用建議

- 將任務寫成明確、可執行的動作，例如「完成簡報大綱」，建議不要只寫「簡報」。
- 優先順序只標示真正重要或急迫的項目；截止日期則用於需要按時完成的任務。
- 善用分類與搜尋整理清單，定期檢視進行中任務，完成後再清理已完成項目。
- 在共用裝置上使用後請登出；清除瀏覽器網站資料可能會移除尚未備份的本機任務。
- 跨裝置使用時，登入同一個 Google 帳號，並在網路連線正常時確認同步完成；重要資料仍建議定期下載 JSON 備份。（備註：可以在「本機儲存」狀態下，下載JSON備份，並在登入後，匯入JSON，即可將「本機儲存」資料存到雲端）

## 瀏覽器與畫面

SparkDay 支援桌面與窄螢幕操作；手機可按標題列的選單按鈕開啟側欄。建議使用近期版本的 Chrome 瀏覽器，以獲得最佳體驗。若 CDN、Google 登入或 Firebase 服務無法連線，相關圖示、特效或雲端功能可能無法使用；本機資料仍以使用中的瀏覽器為準。
